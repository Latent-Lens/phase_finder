The question here is “does PhaseFinder agree with the tools labs already trust, on the same data?” We ran all 30 samples that carry a FlowJo Dean-Jett-Fox answer and all 15 that carry a Flowreader Watson answer, fitting each one under the full pre-model QC ladder, and measured the gap in phase percentages. The headline: with the same data cleanup FlowJo uses, PhaseFinder's Dean-Jett-Fox lands about 4.4 percentage points from FlowJo — and how much QC you apply matters as much as the model.

1. What this shows

Every number below is a mean absolute difference in percentage points (pp) between PhaseFinder's phase fractions and the other tool's, averaged over G1, S and G2/M and over all samples. Smaller is closer. This page is about agreement with other tools; a companion page, Ground-Truth Validation, asks whether we recover a known answer on synthetic data.

Why QC is part of the comparison

A phase fraction is an area under a curve fit to a DNA histogram — and that histogram depends on which events you keep. FlowJo's published numbers came from gated data (debris and junk removed). Comparing our ungated fit to their gated fit isn't apples-to-apples, so we fit every sample under each QC setting and report the whole ladder.

2. How the QC ladder works (and yes, it's cumulative)

PhaseFinder's pre-model QC is a chain of gates, each narrowing the event set the next one sees:

  1. Structural — drop negative, non-finite, and saturated DNA events (debris/junk).
  2. Time QC — drop time windows where acquisition drifted or stalled.
  3. Cell Gate — keep the main cell population on scatter (remove far-out artifacts).
  4. Singlet — remove doublets (two stuck cells that read as double DNA).

So yes — in the app, turning on a later gate keeps all the earlier ones: their masks stack into one final mask. The tables below use that cumulative ladder (each row adds the next gate on top of the previous), which is exactly what a user gets. Section 4 breaks the stack apart to show which single gate is actually doing the work.

3. PhaseFinder Dean-Jett-Fox vs FlowJo (30 samples)

Cumulative ladder — each row adds the next gate:

QC applied|ΔG1||ΔS||ΔG2|Mean gap
No QC (raw)10.85.97.38.0
+ Structural3.33.86.44.5
+ Time QC3.33.76.34.4
+ Cell Gate3.33.76.34.4
+ Singlet (all four)3.93.45.84.4

The gap almost halves the moment structural QC is on (8.0 → 4.5 pp), and the remaining gates barely move it. The clearest signal is G1: ungated it's 10.8 pp off, but with structural gating it drops to 3.3 pp. That swing is pure low-end junk inflating the “one copy” peak — exactly what FlowJo would have cleaned before fitting. In other words, FlowJo's numbers came from debris-cleaned data, and once we match that, we agree to ~4.4 pp.

The residual ~4.4 pp lives mostly in G2/M (5.8 pp) — the S-vs-G2 boundary — which is the genuinely ambiguous part of the histogram, not a formula error (G1 and S are both within ~3.5 pp).

4. Which single gate does the work?

To see each gate's individual contribution, we also ran every gate alone (not stacked) against FlowJo:

Only this gateMean gap vs FlowJo
No QC8.0
Structural only4.5
Time QC only6.1–8.0
Cell Gate only8.0
Singlet only4.9
All four4.4

Structural gating alone (4.5) recovers essentially the entire benefit. Singlet removal helps a little (4.9); Time QC and Cell Gate on their own barely change these particular samples. So the practical rule is simple: to compare against FlowJo, turn on at least Structural QC.

5. PhaseFinder Watson Classic vs Flowreader (15 samples)

Watson Classic is our reproduction of Flowreader's Watson model, so this is the natural comparison. The QC story here is the mirror image:

QC applied|ΔG1||ΔS||ΔG2|Mean gap
No QC (raw)8.310.65.58.2
+ Structural8.420.613.714.3
+ Time QC6.422.016.515.0
+ Cell Gate6.622.016.415.0
+ Singlet (all four)10.522.712.415.2

Here no QC matches Flowreader best (8.2 pp), and gating makes it worse. That tells us Flowreader's Watson reference was computed with little or no gating — a different pipeline choice from FlowJo. It's strong evidence that “which official number you're matching” depends on that tool's own preprocessing, not just its model.

6. Takeaways

  • PhaseFinder matches FlowJo to ~4.4 pp once you apply the same (structural) data cleanup FlowJo uses — down from 8.0 pp on raw data.
  • QC is half the story. The Structural gate closes most of the gap; the others barely move the FlowJo comparison. To reproduce FlowJo-style numbers, keep Structural QC on.
  • The QC gates stack (a later gate keeps the earlier ones), and adding gates never worsened the FlowJo agreement — it plateaus at ~4.4 pp.
  • Different reference tools want different QC. FlowJo used gated data (match it with QC on); Flowreader used ungated data (match it with QC off). This is why PhaseFinder offers both model families and asks you to pick one on purpose.
  • The last few points are inherent. The residual gap sits at the S/G2 boundary — the same region where FlowJo and Flowreader disagree with each other by ~14 pp on S. There is no single 1-pp “true” answer to hit.
