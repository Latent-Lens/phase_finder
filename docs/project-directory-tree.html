PhaseFinder Project Directory Map

A three-level structural overview of the repository, with guidance on what each directory does, whether it is necessary, and whether it belongs in source control.

Runtime source Needed by the browser application or its user-facing help center.
Development support Needed to test, build, validate, secure, or release the application.
Generated or local Rebuildable output, caches, personal state, or tool configuration; normally not committed.

Cleanup guidance

  • Safe to regenerate: dist/, dist-base/, node_modules/, .vite/, every __pycache__/, and test result directories.
  • Keep out of Git: personal sessions, editor lock files, downloaded external validation datasets, credentials, logs, and local tool configuration unless explicitly standardized.
  • Review before deleting: assets/misc/, scientific baselines, provenance manifests, licenses, and workflow sources. They are not runtime dependencies, but may be the only record of a decision or external reference.
  • Never treat as ordinary project content: .git/. It is the repository database, not a source directory.
