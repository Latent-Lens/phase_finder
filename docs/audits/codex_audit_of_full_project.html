Executive summary

Needs work
PhaseFinder is a substantial, promising research application, but this snapshot is not ready for a production release or for unqualified quantitative scientific reporting.

The source application has broad functionality and unusually extensive synthetic tests. However, the release path is broken, the Vite artifact is incomplete, and several modeling and data-interpretation defects can change reported phase fractions or make constraints appear satisfied when they are not.

Full source regression 596 / 596

181 end-to-end checks plus 415 browser unit checks passed.

Production build Builds, incomplete

Vite succeeds on Node 24, but Help and several dynamic assets are missing.

Modeling verdict Structurally sound core

Good numerical foundations, with high-impact constraint and reporting defects.

Scientific validation Not established

No external reference implementation, biological gold standard, or uncertainty analysis.

Bottom line

  • Good foundation: local-first design, vendored D3, modular ES code, index-preserving gates, bin-integrated model mass, Poisson-deviance fitting, multistart optimization, worker isolation, and detailed diagnostics.
  • Release blocker: the Cloudflare workflow calls a nonexistent script and, if that is fixed alone, deploys the repository root instead of the tested dist/ artifact.
  • Scientific blockers: Watson residual S is integrated outside the G1–G2 interval; G2:G1 bounds can be violated by the projector; stalled fits can be labeled converged; Auto can compare against a nonconverged base model; and the plot can show different fractions from the table.
  • Data-validity blocker: the parser does not apply or reject amplification/scaling and compensation metadata before a linear DNA-content model is run.
  • Validation gap: passing self-generated synthetic tests establishes implementation consistency, not numerical equivalence to Dean–Jett–Fox literature or biological accuracy.

Scope and method

This audit reviewed the current working tree, not only the last commit. That matters because the peak-tracking Time QC implementation and related UI/tests were uncommitted at the time of review.

Reviewed statically

index.html, help.html, all first-party CSS and JavaScript, model and numerical modules, FCS parsing/loading, sessions and OPFS, workers, test harnesses, Vite/package configuration, GitHub Actions, release scripts, and tracked session material.

Exercised dynamically

Browser unit harness, Vite production build, source-served Playwright workflow, generated plot exports, and static structure/reference checks. Test artifacts remain git-ignored and were not added to this audit.

Review standard

  • Correctness and internal consistency of UI state and data flow.
  • Scientific correspondence between stated model behavior and implemented equations.
  • Numerical constraints, convergence, diagnostics, and interpretation of outputs.
  • FCS compatibility, input bounds, event-index alignment, memory behavior, and reproducibility.
  • Accessibility, responsive layout, production-only asset behavior, and error feedback.
  • Security/privacy of imported/exported content and release contents.

Meaning of this report: this is a code and numerical-method audit, not an independent biostatistical validation, regulatory review, penetration test, or claim that every browser/device path was exhaustively exercised.

What the code does, feature by feature

1. Local FCS ingestion

Accepts browser file selection and drag/drop, reads FCS HEADER/TEXT first for fast metadata display, rejects duplicate names, and later loads selected DATA columns through a module worker. There is no application data-upload service.

2. Metadata workspace

Maintains a column-oriented sample frame with editable annotations, filename parsing, imported rows, selectable samples, sorting, multi-value filters, removable columns, summary statistics, and TSV import/export.

3. Channel selection and caching

Maps a user-selected DNA-area channel per file, detects corresponding height/width, FSC-A, SSC-A, and Time channels, preserves original event indexes, and caches working arrays for repeated plotting and analysis.

4. Histograms and visualization

Builds raw-count DNA histograms; renders overlays or ridges with D3; supports curves/bins, color grouping, isolation, pan/zoom, axis overrides, region overlays, tooltips, and SVG/PDF/PNG/JPEG export.

5. Structural QC

Creates index-aligned validity masks, rejects nonfinite/negative required values, tracks saturation/range metadata, and provides the base mask consumed by later gates.

6. Time QC

Offers acquisition-rate anomaly detection and a new peak-tracking method. The first summarizes event rate across time bins; the second tracks distribution peaks and scores temporal anomalies. Both can optionally include event-rate information.

7. Scatter and singlet gates

Uses a two-component FSC/SSC Gaussian-mixture heuristic for the main cell population, plus robust PCA on pulse geometry (area/height or area/width) for singlet selection, with manual scatter review.

8. Peak detection and review

Smooths and inspects the masked histogram, proposes G1/G2 regions, assigns confidence and warnings, and exposes accessible slider/keyboard controls for manual region correction.

9. Cell-cycle fitting

Fits Dean–Jett, Dean–Jett–Fox, a pragmatic Watson decomposition, or an automatic DJ/DJF choice. Supports individual and bulk fitting, worker execution, raw-count objectives, contamination terms, report columns, and plot overlays.

10. Diagnostics and reports

Computes phase fractions, residual structure, deviance/information metrics, boundary warnings, tail mass, restart stability, and model-specific details. Results are surfaced in the sidebar, plot, and metadata table.

11. Sessions and local storage

Saves human-readable TOML, caches browser-private FCS copies in OPFS, restores UI/table/model settings, reconnects missing files, and recomputes model fits instead of trusting serialized numeric output.

12. Build, help, and automation

Supports source serving with native modules/import maps and a Vite production build. Includes a help page, responsive styling, unit/E2E harnesses, browser-matrix workflows, release notes, and a Cloudflare Pages release workflow.

Scientific and modeling review

The modeling code is not simply “wrong” or “right.” Its core construction contains several strong numerical choices, but specific implementation defects and missing external validation currently prevent treating all reported fractions as authoritative.

Mathematically strong implementation choices

  • Histogram accounting: js/analysis/dna_histogram.js:108–187 explicitly tracks underflow/overflow and places the exact maximum correctly.
  • Integrated peak mass: gaussian_bin_mass.js:40–55 integrates Gaussian probability over bin edges instead of point-sampling bin centers.
  • Dean–Jett S component: models/shared.js:119–167 normalizes the quadratic interphase profile and independently integrates CV-dependent broadening.
  • DJF nesting: dean_jett_fox.js:128–165 applies latent wave broadening before the Dean–Jett broadening and reduces to DJ when wave weight is zero.
  • Objective: fit_engine.js:49–65 fits raw counts using Poisson-deviance residuals rather than fitting smoothed display curves.
  • Determinism and diagnostics: deterministic multistart, retained candidate diagnostics, tail mass, bound warnings, residual autocorrelation, and restart stability are all valuable safeguards.
HighSCI-01

Watson S-phase fraction includes contamination outside the S interval

The implementation computes max(0, observed - G1 - G2) for every histogram bin and normalizes that total as S phase. The project plan states that residual S should be limited to the interval between fitted G1 and G2 centers.

Evidence
js/analysis/cell_cycle/models/watson_pragmatic.js:181–185,208–217; intended behavior in docs/plans/cell_cycle_modeling_plan.md:570–577.
Impact
Sub-G1 debris, baseline, and aggregates beyond G2 can materially inflate %S while still producing a plausible-looking decomposition.
Remediation
Restrict residual integration to the declared S interval, or explicitly model/exclude contamination. Add quantitative recovery tests, not only “S is nonzero” tests.
HighSCI-02

G2:G1 ratio constraints are not guaranteed

The projection clamps G1 and G2 independently, adjusts G2 for the ratio, and then clamps G2 back into its region. That final clamp can reintroduce a ratio violation even when a feasible pair exists elsewhere.

Evidence
dean_jett.js:129–147 and dean_jett_fox.js:174–191. For G1 region [1,10], G2 region [18,20], ratio [1.65,2.25], proposed G1=1 can return G2=18, a ratio of 18.
Impact
A fit can be displayed as bounded while violating a biologically important DNA-content relationship.
Remediation
Jointly project the pair onto the feasible intersection or parameterize G2 as G1 multiplied by a smoothly bounded ratio. Assert every final result satisfies every constraint.
HighSCI-03/04

Convergence and automatic model validity are overstated

The LM solver terminates when relative deviance improvement is small or the parameter step is small, yet labels the reason as if both occurred. Auto selection explicitly requires DJF convergence but not base DJ convergence.

Evidence
math/lm_solver.js:382–405; result mapping in dean_jett.js:282–285 and dean_jett_fox.js:350–354; comparison in model_selection.js:103–152.
Impact
Stalled/ill-conditioned fits can look converged, and Fox may be chosen against an invalid baseline—or a nonconverged DJ may remain the default.
Remediation
Report distinct termination reasons; require explicit objective, step, and preferably gradient/conditioning checks; require both candidates to be valid or return “no valid model.”
HighSCI-05/06

Displayed and bulk-applied scientific quantities can diverge

The plot recomputes fractions from model mass inside the displayed histogram while the table/sidebar use canonical fit fractions. Separately, Auto-Fit All averages absolute region limits across samples without checking shared calibration and includes low-confidence/inferred proposals.

Evidence
js/plotting/render.js:154–213; canonical fractions in dean_jett.js:403–409 and dean_jett_fox.js:464–467; bulk logic in modeling_ui.js:226–279.
Impact
Users can see different %G1/%S/%G2 for the same fit, while one atypical or differently scaled sample can bias every bulk fit.
Remediation
Use fit.phaseFractions everywhere; label domain-limited summaries separately. Gate bulk sharing on compatible channel calibration and robust, reviewed normalized regions.

Further scientific limitations

  • Conditioning: areas, channel coordinates, CVs, and shape values are optimized on very different raw scales with hard projections and finite-difference normal equations. The design plan called for dimensionless/log/logit parameterization.
  • S-profile positivity: invalid quadratic profiles are clipped and repeatedly multiplied by 0.7 until positive. This undocumented nonsmooth repair changes the candidate shape rather than rejecting it or guaranteeing validity through parameterization.
  • Model-selection threshold: any decrease in absolute lag-1 residual autocorrelation counts as improvement; there is no material-effect threshold despite the UI/policy language.
  • Absolute information metrics: the Poisson factorial constant is omitted. Within-histogram model deltas remain valid because the constant cancels, but the displayed absolute likelihood/AIC/BIC are nonstandard and should not be compared across samples or external tools.
  • No uncertainty: there are no confidence intervals, bootstrap distributions, profile likelihoods, or identifiability/condition-number diagnostics for phase fractions and model parameters.
  • Legacy/canonical overlap: stages 5–8 of cell_cycle_pipeline.js retain a legacy bridge while canonical fitting uses separate model state. The UI and documentation should state which result is authoritative.

Scientific readiness conclusion: DJ and DJF are structurally consistent with the intended model family, but they are not yet demonstrated numerically equivalent to a published reference implementation. Watson does not currently implement its intended S-range rule. Do not use this snapshot for publication-grade, clinical, or irreversible biological decisions without correcting the high findings and benchmarking against established software and annotated datasets.

HTML, CSS, and frontend behavior

The frontend is modular and feature rich, with generally careful escaping and several good accessibility details. The major problems are production-only assets, mobile reachability, scientific-settings state, swallowed errors, and incomplete keyboard/screen-reader support.

Verified strengths

  • No duplicate IDs or missing label targets were found in the main page.
  • Static source-page images have alternative text; dynamic user strings are generally escaped or assigned with textContent.
  • Peak-region sliders expose good keyboard and ARIA semantics.
  • Collapsed panels synchronize aria-expanded, aria-hidden, and inert.
  • Viewport panning coalesces redraws through requestAnimationFrame.
  • CSS braces and source asset references were structurally intact, except the stale release-preview stylesheet.
HighUI-01

Time QC modal can save invalid or cancelled state

“Reset defaults” mutates shared settings immediately; pressing Cancel afterward returns null but does not roll the mutation back. Apply checks only that values are finite and does not enforce HTML min/max constraints, and restored session values bypass HTML validation entirely.

Evidence
time_qc_modal.js:9,119–182; time_qc_settings.js:82–102; numeric declarations around index.html:572,590.
Impact
Negative counts, invalid overlap, or out-of-range thresholds can enter scientific calculations; Cancel may unexpectedly change the analysis.
Remediation
Edit a modal-local draft, validate complete cross-field constraints in one schema, commit only on Apply, and validate session-restored settings through the same function.
HighUI-02

QC exceptions are reported as success

pipeline_ui.js:327 catches stage exceptions without surfacing the failure, then line 356 always reports “Pre-model QC applied.” Expected insufficient-data skips and unexpected programming/data errors are indistinguishable.

Impact
A user can proceed to modeling believing requested QC ran successfully when it crashed or silently degraded.
Remediation
Use typed expected-skip results; fail closed on unexpected exceptions; display per-sample stage status; block downstream fitting when a required stage fails.
HighUI-03

Mobile layout can make content unreachable

The body disables scrolling, while the app height assumes a 60px header. At the mobile breakpoint, the header grows and the sidebar/workspace stack vertically, but the viewport calculation is not reconciled.

Evidence
css/base.css:62, css/layout.css:148, and css/responsive.css:3.
Remediation
Allow document scrolling on stacked layouts or use a single dynamic viewport grid with min-height: 0 on internal scroll regions; test narrow/short viewports and mobile browser chrome.

FCS data, sessions, reproducibility, and security

HighDATA-01

The model can accept a channel that is not linear DNA content

The parser reads stored F/D/I values but does not apply or explicitly reject $PnE/$PnG amplification/scaling, compensation/spillover, non-list $MODE, or chained $NEXTDATA datasets. Amplification metadata is recorded, not used.

Evidence
js/fcs/parser.js:267–305,392–435; js/fcs/channel_cleaning.js:272–286.
Impact
DJ/DJF can converge numerically on log-amplified, uncompensated, or otherwise unsuitable values while producing scientifically meaningless G1/G2 positions and fractions.
Remediation
Before modeling, require list mode and a verified supported linear DNA channel. Apply documented transforms/compensation where supported; otherwise block with a specific explanation.
HighSES-01/02

Cached files can orphan, and restored file identity is weak

A fresh runtime session ID is generated each load, while restored records can point to an older OPFS path. Reset deletes only the current runtime directory. Reconnect accepts OPFS content by size and manual content by filename plus size; no digest proves it is the same sample.

Evidence
file_cache.js:206,235,299; core.js:425–435; reconnect.js:27–64.
Impact
Large private FCS copies can accumulate without cleanup, and a same-name/same-size replacement can silently undermine scientific reproducibility.
Remediation
Persist ownership/index metadata for every cached object; delete all session-referenced paths on reset; offer cache inventory/clear controls; store and verify SHA-256 digests.

Parser robustness and memory

  • TEXT/DATA offsets and $TOT × event_stride are not fully checked against file/buffer size before reads and allocation.
  • Integer parsing assumes ceil(bits/8) byte-aligned fields; non-byte-aligned encodings and integers above JavaScript's exact 53-bit range should be implemented correctly or rejected.
  • Selected-column loading still slices the whole DATA segment, allocates normal arrays, then creates Float64Array copies. Four-file concurrency can amplify peak memory.
  • Companion channel failures are caught and warned, but Time/scatter/singlet QC can then skip while modeling remains available. Requested mandatory gates should fail closed.
  • Current parser fixtures cover little-endian float32 and 16-bit integer happy paths, not double, big-endian, truncation, escaped delimiters, supplemental TEXT, unusual bit widths, or multiple datasets.

CI and toolchain findings

  • Broken native Safari workflow: the legacy workflow referenced dependency and test paths that did not exist.
  • WebKit is not native Safari: the main compatibility matrix labels Playwright WebKit as “safari.” That is useful engine coverage, but should be named WebKit and not presented as native browser validation.
  • Unit phase can disappear: drive_flow.py:203 catches unit-run exceptions and only prints a warning; exit status at line 228 checks recorded FAIL rows. A completely missing unit phase can therefore return success.
  • Source-only E2E: the browser runner serves the repository root, never dist/. Production-only Help/icon/manifest/preload failures escape the regression gate.
  • Node reproducibility: package.json lacks engines and a committed version pin. Vite 8 requires Node ^20.19.0 || >=22.12.0; the available Node 18.19.1 fails, while Node 24.16.0 builds successfully.
  • No npm test contract: package scripts expose dev/build/preview only. GitHub/Cloudflare cannot use a conventional npm test gate without custom knowledge.
  • Pre-commit drift: documentation says dirty worktrees are blocked, but the relevant exits are commented out in .githooks/pre-commit:11,26.

Documentation drift

Notable strengths worth preserving

  • Privacy-oriented architecture: runtime analysis is browser-local, D3 is vendored, and no analytics/upload service was found.
  • Good separation of concerns: UI, state, FCS, plotting, scientific analysis, sessions, and workers are split into focused ES modules.
  • Index alignment: masks and companion channels preserve source event indexing across staged QC.
  • Model transparency: components, diagnostics, bounds, restarts, and warnings are retained rather than hiding the fit behind one percentage.
  • Recomputation on restore: sessions restore inputs/settings and recompute fits instead of trusting stale serialized scientific results.
  • Performance awareness: header-first loading, deferred companion channels, worker transfer buffers, limited concurrency, and animation-frame redraw coalescing are sensible.
  • Escaping discipline: user-derived strings are generally escaped in tables, status/progress UI, tooltips, fit displays, and reconnect views.
  • Deep test investment: 415 browser unit checks cover many numeric components, boundaries, worker parity, selection policy, and Time QC paths.

Prioritized remediation roadmap

  1. Stop unsafe/incomplete releases

    Fix the release script path; pin Node; build and test dist/; add Help and dynamic assets; deploy only dist/; remove/ignore personal session/tooling material; repair or disable the broken Safari workflow until its tests exist.

  2. Correct scientific result integrity

    Limit Watson S residuals; guarantee ratio constraints; make convergence reasons honest and strict; require valid DJ and DJF candidates; unify phase-fraction consumers; validate calibrated regions before bulk fitting.

  3. Gate valid FCS inputs and QC execution

    Validate list mode, scaling/amplification, compensation, data bounds, integer representation, and dataset count. Treat required companion-channel or stage failures as explicit blocking states, not success.

  4. Make sessions reproducible and storage manageable

    Add content digests, cache ownership/indexing, comprehensive reset/clear controls, schema-validated TOML, prototype-safe parsing, and regression tests that inspect OPFS.

  5. Harden the frontend

  6. Establish independent scientific validity

    Freeze representative reference FCS datasets; compare component curves and fractions with literature equations and established software; test known mixtures/perturbations; add uncertainty and identifiability measures; document supported instruments/transforms and acceptance tolerances.
