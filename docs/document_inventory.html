What is still in docs/, and why?

Remaining outside archive does not mean a file was skipped, and it does not mean it cannot be archived. The previous pass removed superseded issue queues while retaining references, specifications, evidence and generators. That was conservative: some historical files could also have moved. This inventory states that directly, rather than treating every retained file as necessary or fully current.

A document can still be useful after its implementation tasks are complete: its equations, behavior contract or regeneration instructions remain relevant. Conversely, a stale snapshot does not need to stay active just because it contains useful history. The master checklist remains the only issue tracker.
